# TEXT-HISTORY01：历史采样条数不是诊断行数

## 实际失败

2026-11-14 10:07 的既有自然巡检未发现锁等待，但建议核查“文本项8行”与“锁快照0行”的差异。实际是原始文本监控项保留了8条历史采样，内容未授权交给外部模型；规范化锁快照为0行。二者不具有同一种计数含义。这是模型输入的类型歧义，不是已发现的数据库故障。

## 最小优化

外部证据投影对省略原文的 Zabbix 文本、日志及未知类型监控项，不再给出通用 `row_count`；改为 `history_sample_count` 并附 `projected_history_entries_not_diagnostic_rows` 范围。它只表示有界投影中的历史条目数，不代表完整历史数量、文本内的诊断行数或系统健康。MySQL 规范化诊断快照仍使用原有行数。初始输入、最终输入与工具结果均保留该范围说明；没有放开原文访问。
