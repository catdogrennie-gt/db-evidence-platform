# 公开演示验收 · 2026-11-09

本轮新增固定 Lab 问题开关、真实进度、恢复复验和受限公开账号。实验是合成订单负载下的真实 MySQL 锁等待，监控来自实际 Zabbix 采样；不是生产事故或自动修复案例。

## 已核对的执行边界

- 使用两个独立 API 进程同时提交开启请求，控制库只接受一轮实验，两端返回同一轮次。并发控制不依赖网页禁用按钮或单进程内存锁。
- 专用 MySQL 身份最多两个连接，只能读取身份标记 / 合成订单表，以及更新合成订单表。事务只用于制造等待，退出时回滚；没有提交、任意 SQL 或通用故障接口。
- 注入前核对数据库 UUID、隔离容器标记、网络和数据摘要。相对时限与持久化绝对截止时间共同约束，超过截止时间不新建故障连接；连接自身另有限时保护。
- 公开账号仅获固定联合对象的读取与演示开关权限。实际 HTTP 检查确认通用模型分析、任意采集、巡检配置修改均被拒绝；跨来源 / 对象访问及 CSRF 约束仍生效。
- 新鲜故障证据必须匹配来源、host、item、映射 / 配置版本和本轮时间，具有明确完整性及非空锁行。必需锁证据被固定到本轮清单，并核对实际有界模型上下文中仍有对应锁行。历史截断缺口不会被清除。
- 停止先检查专用连接、锁与实验数据，再等待 Zabbix 新的完整空锁快照。缺少任一证明时不把倒计时或关闭按钮当作恢复成功。
