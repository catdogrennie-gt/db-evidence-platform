# 内部 AI 数据库运维平台设计

日期：2026-11-08。状态：设计基线 v1 已完成独立一致性检查；可点击原型的代表性路径已在浏览器复验。平台已按该基线实施，实际通过、待验和未实现范围以[验收记录](06-acceptance-status.md)为准；设计指标不等于已达标。

本设计以内部数据库运维平台为目标，首批完整支持 MySQL，之后通过适配器扩展 PostgreSQL。原有固定数据库实验只作为验证资产及故障场景。原 `docs/01-requirements.txt` 中“单人本机、不增加多用户”等范围不能作为平台建设约束。

主流程为：接入并确定责任归属 → 持续采集 → 规则发现及事件归并 → AI按授权资产与时间窗关联证据 → 人工确认处置 → 复验 → 留存知识。

设计图中的示例名称、数值和界面状态用于表达交互，不能当作实际采集结果。平台交付必须以新实例接入、持续采集、权限隔离、真实故障处置及重启恢复等证据验收。
