### TLS 修复依据

锁定驱动为 PyMySQL 1.1.2。已读取本地安装源码并于记录日核对[官方 v1.1.2 连接实现](https://github.com/PyMySQL/PyMySQL/blob/v1.1.2/pymysql/connections.py)及[同版原始源码](https://raw.githubusercontent.com/PyMySQL/PyMySQL/v1.1.2/pymysql/connections.py)：`_request_authentication` 仅在服务端声明 SSL 能力时执行 TLS 包装。平台通过一个小型连接子类在进入父认证方法前拒绝无 SSL 能力，并在包装返回前要求经 CA/主机名验证的真实 TLS socket 和协商 cipher；没有复制驱动认证实现。

官方原始源码 SHA-256：`11c68d8b28567c94780775123b333815a2404533eafd74f157ffae4b669530a0`。本地安装文件字节摘要因打包换行不同，逐行内容核对一致。回归见 [test_connector_tls.py](../../tests/platform/test_connector_tls.py)，涵盖缺 CA、缺服务端 SSL 能力、无 cipher、证书信任与主机名失败。另用显式私密配置执行 test_connector_tls_live.py，C 真实 MySQL 四项通过，详见 E16。C 当前登记未切换 TLS，凭据轮换与缺主密钥异常仍列待验。
