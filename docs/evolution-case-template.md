# 单问题演进场景卡

复制本模板记录一个问题，全程沿用同一编号和累计计时。原始请求、连接信息和敏感样本保存在仓库外，公开卡片只留脱敏事实与证据索引。

## 目标与准备

| 项目 | 开始前填写 |
|---|---|
| 编号、难度、阶段、累计用时 | 一个问题；阶段区分准备、复现、检查、修复、重测、发布、暂停 |
| 现象及业务影响 | 谁受影响，出现什么现象，最低希望判断到哪一层 |
| 实际 Zabbix 对照 | 模板/触发器/宏与事件；已有告警解释增强、配置覆盖缺口或风险线索，不泛称产品无法告警 |
| 正常反例 | 哪种正常变化与故障相似，怎样避免误报 |
| 预期流程 | 正常样本 → 实际异常变化 → 自主检查 → 冻结证据 → 报告 → 关闭 → 新鲜恢复样本 |
| 独立复现验收 | 如何在平台外确认预期上游变化；不向模型传故障标签或答案 |
| 安全及还原 | 登记隔离目标、固定身份/资源上限、单控制器、独立清理、最长时限、原巡检周期 |
| 准备结论 | GO / WAIT / SKIP；未满足的条件、能否补齐、下一动作 |
