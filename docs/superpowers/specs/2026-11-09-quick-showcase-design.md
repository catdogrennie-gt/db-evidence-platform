# 快速演示站 A 与完整平台 B

本设计取代先前“平台内限次实验页”的产品方向，按用户最终澄清执行。实现方式由开发者负责，不再重新要求用户选择架构。

## 产品边界

- A：免登录的快速功能演示。一个固定 MySQL 锁等待开关，开启持续制造同一问题，关闭回滚。重复开启不增加故障连接，没有次数、冷却或等待 Zabbix 恢复才能操作的门槛。A 同页展示 B 的实际监控、发现状态、AI 摘要与图表。
- B：原有完整项目系统，提供精确对象范围的只读公开账号，仍由自己的 Zabbix 采集、正常巡检和 AI 队列发现及解释问题。
- 两个公网地址。A 调用 B 的受限服务接口，不复制分析系统、不访问 B 的控制库、不直接创建报告或替 B 下结论。
- A 开启时临时调整 B 的实际采集与信号检查周期，关闭后恢复基线。页面明确标注正常/加速周期与实际最近采样、检查及报告时间。

## 实现选择

复用 SignalLens-Lab 仓库增加轻量 A 网站，保留既有命令行案例；B 保持 db-evidence-platform。只新增固定范围的服务接口和临时周期租约。不让浏览器持有 B 的服务凭据，也不把 B 的完整 API 匿名开放。

### A

独立进程 18210，静态 HTML/CSS/JS 与 FastAPI。一个 controller 串行落实 `desired_on`，API 请求只改变期望状态，不排队累积实验。专用故障身份最多两个 MySQL 连接；holder 短超时、定期续期，controller 丢失后自动回滚。OFF 优先释放事务，最新 ON 可以在实际回滚后直接开始，不等监控系统证明恢复。

目标、SQL、UUID、容器/网络/标记和基线数据摘要均固定于仓库外私密配置。安全观测用于目标守卫，不冒充 B 的业务采样。重启默认 OFF，不重放旧故障。

接口：`GET /api/state`；`PUT /api/switch {"on":bool}`。状态含 `desired_on/actual_state/revision/updated_at/error_code` 和 B 的投影。拒绝额外输入，写请求检查同源 Origin。A 仅访问 B 的下列两个服务接口。

### B 服务接口

私密 `showcase` 配置显式启用，包含固定实例、正常巡检策略、只读身份和独立随机服务 token 文件。Bearer token 只允许此固定投影及临时周期，不成为一般用户凭据。

- `GET /api/v1/showcase/snapshot`：固定目标的最近完整锁快照观测、最近真实检查、AI 任务阶段、已有报告摘要与最多三条实际数值曲线。保留时间、来源、缺口和模型状态；无数据不补零，无报告不伪造进度。
- `PUT /api/v1/showcase/pacing {"enabled":bool}`：启用/续期或解除固定对象的加速租约。A 每 10 秒续期，租约 45 秒，A/网络失联后由 B worker 恢复原周期。实际 collection 10 秒、signal 5 秒；定期综合 AI 不高频重复运行，异常仍由普通 urgent 通道决定。

周期变化保留基线，恢复时不覆盖管理员同时修改的新设置；不重置调用历史、不创建 Investigation、不直接调用模型。报告按实际异常 episode 去重；真正的新鲜空快照用于后台恢复和再次发现，不限制故障开关。

## 必要平台修正

普通巡检应识别 v2 完整当前快照，即使最近历史因保留上限裁剪；历史缺口照常保留。真正的空样本解除当前观测并允许下一次异常重新分析。同一活跃异常不重复堆积任务。只读访客按可见对象看到真实后台巡检状态，而非只查自己拥有的策略。实际采集周期写入证据元数据。

旧平台内 Demo 控制器停用，公开 demo 身份移除 `demo.operate` 并撤销旧会话。既有报告、失败记录和历史 Release 保留。

## 验收

匿名 A 实际 ON/OFF/ON（不中途等 Zabbix）；重复/并发 ON 不增加连接；关闭数据不变；controller 硬终止后短租约实际回滚。B 周期实际改变，OFF/租约失效恢复基线。不开任何演示专用分析接口，由普通 B scheduler 自主生成真实调查；A 展示同一报告和实际曲线。B 公开账号写入均拒绝。两站 Chrome 与公网检查、私密值扫描、README 两入口与账号、公开源码 readback。
