# Zabbix 版本探测的认证边界

DATA-STALE01 前检发现：实际 Zabbix 7.0.32 可正常读取主机和历史，但复用带 token 的只读客户端请求 `apiinfo.version` 会收到拒绝，被适配器概括为上游不可用。匿名请求同一方法可成功。

[官方接口说明](https://www.zabbix.com/documentation/7.0/en/manual/api/reference/apiinfo/version)将版本方法限定为匿名调用。只对这一已登记方法省去认证头；主机、监控项和历史读取继续使用各自来源 token，写方法、超时、体积限制和调用上限保持原样。通过每个请求构造独立头，避免连接复用时串用认证。

不全局移除认证，不扩大方法白名单，也不把版本探测通过当作监控数据读取授权或源完整性证明。先运行失败回归，再最小修复；覆盖独立请求及复用连接中匿名/认证交替的真实 HTTP 客户端路径。

源码与干净公开候选测试通过后再发布。实际已封存服务不覆盖；源码检查、真实只读命令验收和运行版本部署分别记录。
