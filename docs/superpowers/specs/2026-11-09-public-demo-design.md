# 受限公网演示设计

用户目标：README 提供专用演示账号，访客进入独立演示页，以一个开关触发、解除固定问题，看到实际采集和分析进度及结论。沿用当前 Zabbix 联合分析和结论优先报告。

## 方案与取舍

采用真实隔离 Lab 的单行事务阻塞。静态回放不能展示当前 Zabbix→分析链路；公开通用故障/SQL控制台会越出演示范围。页面不接受目标、SQL、命令、时长、模型或提示词。控制参数全部来自仓库外私密配置。

这是实现者根据用户授权作出的选择：180 秒自动解除、全站同时一轮、结束后 600 秒冷却、UTC 当日最多 8 轮，其中最多 4 次真实模型分析。不改原自动巡检的 6 次预算；模型仍使用现有输入/输出/调用限制。额度不足明确展示，保留上次历史报告，不冒充新分析。

## 页面与操作

新增“演示” `/demo`，现有四个核心入口保留。此页隐藏全局对象/时间筛选，固定显示实验对象、来源、剩余时间和共享演示说明。

开关开启 → 准备/身份核对 → 实际锁等待 → 等待 Zabbix 证据 → 固定问题综合分析 → 查看报告。用户可随时关闭；180秒也自动关闭。解除事务、直接校验和 Zabbix 恢复采样分别显示。分析可以在事务解除后继续，报告严格绑定本轮冻结窗口。没有新鲜非空锁快照不调用模型；没有新鲜空锁快照不声称监控复验通过。

进度使用服务端里程碑与时间，不绘制虚构百分比。网络错误保留上次状态但明确已过期。恢复未确认时阻止再次开始。页面优先显示真实模型的摘要、原因与操作，过程/图表沿用报告组件按需展开。

## 权限与执行边界

公开 `demo` 用户：仅固定 Lab 联合对象的读取与 `demo.operate`，无敏感文本、通用分析创建、模型外发、采集触发、配置、导出或任意 Lab 操作权限。模型分析由独立最小权限服务身份发起，公开账号不能调用通用 API 绕过额度。

登录仍使用既有 CSRF、Origin、Secure Cookie 和会话撤销。公开密码是此演示身份专用，不能成为新安装默认密码。README 明确临时域名及共享实验数据。

后端持久化全站互斥、运行历史、停止请求、不可延长的截止时间、worker租约、证据/调查关联、限额与清理结果。多API进程不各自注入。worker死亡不自动重放故障，恢复核对前不放开新任务。

注入仅连接私密配置指定、UUID和Lab标记核对通过的隔离 MySQL。只执行固定行 UPDATE，永不 COMMIT；阻塞/等待事务均回滚。专用账号仅可读标记和实验行、更新该表。持锁连接有服务端空闲超时，独立本机看门狗还会在最大时限关闭；正常控制链路每次轮询同时检查时限。停止只关闭本轮连接，不 KILL 其他会话。

## 契约

`GET /api/v1/demo` 返回固定对象、能力、限制/预算、server_time、cooldown_until、当前或最近 run、近期历史、可授权读取的最新报告。`POST /demo/start` 和 `POST /demo/stop` 无参数（拒绝额外字段），幂等操作同一全站状态。start只能启用固定实验，stop始终优先于冷却/预算。

run 包括 `id/status/phase/fault_state/started_at/expires_at/stopped_at/stop_requested/evidence_id/observed_at/investigation_id/analysis_status/error_code/cleanup/steps`。顶层报告使用现有 investigation_detail 投影。错误只公开稳定代码与简短提示，不回传连接异常原文、私密路径或凭据。

Transport 接口位于 `platform_app/demo_fault.py`：`FixedLabFault(config)`；`start()`核对身份并制造等待；`sample()`返回本轮实时活动状态；`stop()`回滚并返回清理校验；`verify_idle(config)`用于重启后不注入的恢复检查。构造和状态不暴露凭据。worker实例独占 transport，API只改持久意图。

## 验收

测试无权限/跨对象/额外输入/CSRF、并发start、冷却/UTC预算、断进程/过期自动清理、不重放、旧证据拒绝、缺失恢复不误判、模型失败/额度不足不伪造结论。真实验收至少一轮开启→Zabbix非空锁证据→真实模型→停止→回滚且数据不变→Zabbix新鲜空锁快照，并检查公网演示账号无法修改配置和通用分析。保留实际失败和准确性限制。
