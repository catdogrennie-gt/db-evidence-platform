# 当前部署的恢复前检查

STARTUP-01于2026-11-13 18:49开始。现有桌面入口仍指向历史控制库和18080，当前部署为API/前端17、采集16、AI18及独立A入口；没有找到相应自启动登记。这是运行恢复缺项，不是新数据库诊断场景。当前公网正常，不做重启实验。

采用只读的部署指纹检查，先把启动缺项与冲突变成可执行、可检查的结果。不直接安装自启动：当前缺少完整依赖恢复、控制器清理和临时隧道变址更新的冷启动验证，自动重复执行旧启动脚本会拉起错误平台。也不本轮重写全部服务管理。

私密清单登记所需进程的可执行路径、命令行哈希、创建时间、PID及父PID、监听端口和依赖名称；原始命令行及实际部署配置不进入仓库。通用检查器只读对照新鲜Windows进程/端口快照，区分正常、缺失、身份变化、重复、端口冲突和依赖阻塞。PID相同不代表身份相同，已存在的错误进程不得被当成可接管对象。结果只含组件逻辑名称、状态和原因码，不打印命令、口令、路径或完整异常。

本轮提供可执行检查与真实只读验收，不自动启动、终止、重载或改配置；旧入口保留但明确不可用于当前演进版。完整冷启动和开机恢复继续WAIT，后续有界接入统一恢复顺序后再替换入口和登记自启动。检查器不能把“当前运行正常”升级为“电脑重启恢复通过”。

验收包含PID复用、命令漂移、重复消费者、端口被占、缺失依赖、父PID变化、无效清单、未知/重复组件及正常反例；真实环境开始与收尾检查公网，控制器保持关闭，不消耗模型额度。
