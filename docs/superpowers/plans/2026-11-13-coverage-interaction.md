# 覆盖缺口明细与入口纠正

**Goal:** 点击覆盖提示立即看见具体对象、数据项、原因与补齐办法；没有明细不显示空泛警告。

**Design:** 首页原位展开明细，保留阅读位置。后端只统计当前授权、当前选中的监控项，不把未选择的 text/log 值类型误当必需能力。区分当前采集状态与所选历史窗口、冻结报告；不引入上游网络请求或扫描证据正文。

- [x] 用回归复现未选日志误报、缺口无明细、越权/筛选和稀疏历史误判。
- [x] 新增纯覆盖投影，首页返回有身份的缺口列表及截断说明。
- [x] 原位展示缺什么、影响与操作建议；对象数据下钻携带实例，报告覆盖只显示冻结报告自身内容。
- [x] 核对其他入口的标签、目标和只读身份，修正管理按钮与查看按钮混用。
- [x] 相关测试、独立评审、封存候选与公网切换、只读和旧报告回查；维护手册。

随后恢复数据准备与单问题演进；保留上一轮真实采集和测试证据，不把交互修正视作诊断场景通过。

验证：27 项覆盖/列表回归、57 项相关后端、98 项前端检查与生产构建通过；独立公开源码快照的 146 项相关后端检查通过。已切换 API/前端到 evolution-release-11，后台采集与 AI 保持版本 10。公开登录、静态资源、旧报告读取通过；浏览器工具超时，视觉验收仍待补做。
