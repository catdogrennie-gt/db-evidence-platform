# 恢复前检查实施计划

**Goal:** 对当前部署提供只读、拒绝混用历史服务的启动前检查。

**Architecture:** 纯函数校验私密组件清单与新鲜进程/监听快照；CLI只输出脱敏逻辑状态。Windows私密适配器负责获取数据，不进入公开仓库。既有运行和旧启动脚本本轮均不修改。

**Spec:** [恢复前检查设计](../specs/2026-11-13-runtime-preflight-design.md)。这是原持续执行授权范围内的工程选择。

## 约束与审查重点

- 无启动、停止、Shell/SQL执行或外部模型调用能力；输入仅本机私密JSON。
- PID、父PID、创建时间、路径和命令指纹共同验证，拒绝模糊接管。
- 端口冲突、重复进程、缺失依赖与健康分开；未知身份不当成正常。
- 对外输出无原命令、私密路径或未过滤异常；无数据不能称健康。
- 仅当前只读验收，冷启动、自启动和临时网址恢复仍WAIT。
